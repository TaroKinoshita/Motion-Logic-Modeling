# 同じ映像担当の7抜粋と別担当の6抜粋の比較

2026-11-20。Lyricsample1〜7は同じ映像担当、LyricOther1〜6は互いに別の映像担当としてユーザーが提供した。13ファイルのSHA256はすべて異なる。元作品・曲・シリーズの対応と担当範囲は未照合。この試験では、未知の1抜粋が同じ映像担当の参考群に近いかを二群で判定する。

## 作風の候補

中央5秒の測定では、各抜粋の前景占有率の中央値を群内でさらに中央値にすると参考群1.33%、対照群5.57%。最大領域を囲む矩形の面積比は参考群1.62%、対照群8.06%。前景占有率の時間方向の四分位範囲にも、参考群4.34ポイント、対照群7.69ポイントの差が出た。今回の抜粋では、何がどれだけ画面を埋めるか、その変化幅に候補が見える。背景色・模様・コントラストでも抽出範囲が変わるので、意味上の主役や余白の設計を確認するには字・語・図形を分けて測る必要がある。

対照の抜き出しコマでも、LyricOther4の33F・166Fの大きな字形と回転、LyricOther6の109F・254Fの大小差、LyricOther2の150F・251Fの大きな文字と枠・模様を確認した。大小差の存在、回転の存在、枠の存在だけで担当を区別することはできない。合字・分解の意味、急停止や縮小など個々の動きの曲線、音に対する先行／遅延は今回の分類に入れていない。今回の判定から、入力に応じて演出を選ぶ制約の重みは推定しない。

## 方法と再実行

両群とも、冒頭・中央・末尾から各5秒を取り、480×270・秒間12標本で測定した。素材の長さとフレームレートの違いを揃えるため、標本には最も近い元フレームを使用し、速度は元フレーム間の秒差で換算した。主設定は中央5秒・行ごとの背景との差・構図と動き。背景差分と輪郭付近の局所コントラストによる2通りの前景推定を用いた。動きは大きな画面変化を除いた前景付近のオプティカルフローで、カメラや模様の影響も含む。矩形とフローが計測できたコマ数は品質の確認に使った。

一度に1抜粋を取り除き、残りの抜粋だけで各項目を標準化し、二群のどちらの平均に近いかを比較した。均衡正答率は両群の正答率を等しく重み付けした平均で、片方の群に固定する基準は50%。長い対照素材の全区間や、初見の元作品での判定は今後の検証対象。Lyricsample7は主設定では画面に写っている内容を観測し、そのエフェクトの影響を見るため7を除外した判定も別途保存した。
