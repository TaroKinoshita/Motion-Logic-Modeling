# 拡大・縮小を選ぶ直前の画面を比較

2026-11-20。[表示が続く区間の比較](31_Phrase_Continuation_Opportunities.md)から16区間と、別枠の既知の縮小4件を再計測した。拡大の2区間と縮小4件では変化の直前、表示が続く14区間では抽出区間の中央を観測点にした。したがって、以下は選択条件を比較する探索で、連続映像に対する予測成績ではない。

## 比較結果

| 選び方 | 等間隔に採った16区間 | 既知の縮小4件 |
| --- | ---: | ---: |
| 常に表示を維持 | 14/16 | 0/4 |
| 画面幅の50%以上を占めていれば縮小、それ以外は維持 | 10/16 | 2/4 |
| 画面幅の25%以下なら拡大、50%以上なら縮小、その間は維持 | 7/16 | 2/4 |
| 過去約0.33秒に同じ語が1コマで縦横とも1.40倍以上になっていれば縮小、それ以外は維持 | 14/16 | 1/4 |

25%・50%・1.40倍は挙動を比較するための基準。予測結果を見て最適な閾値を選ぶ工程は行っていない。画面幅と面積は、元解像度で測った主な文字列の外接矩形から算出した。背景の図形が混じらないように区間ごとに領域と明暗・色の抽出方法を指定し、矩形を元コマに重ねて確認した。占有面積は外接矩形の面積で、字のインク面積とは異なる。既知の縮小4件は発見に使った2本なので、16区間と合算して成績を出さない。

## どこで外れたか

- **大きさ。** 縮小の直前、Lyricsample5の「ユラユラ」「カラカラ」の幅は画面の約47%。Lyricsample6の「やめろよ」は約93%、「回った」は約72%だった。一方、LyricOther6の大きい文字列は約76%あっても続けて表示された。文字列の大きさだけで4件の縮小を拾おうとすると、縮小しない例も含まれる。
- **直前の拡大。** 「やめろよ」は119→120Fで幅1.85倍・高さ1.66倍になり、128→129Fで縮小した。「回った」では縮小前約0.33秒を同じ語として確認でき、この間に同程度の拡大はなかった。Lyricsample5の2件は直前に字形が強く変形しており、同じ語の寸法として比較できない区間があった。等間隔の16区間でも、全履歴を同じ文字列で測れたのは4区間。履歴が不明な場合は、比較上は表示維持に戻す規則を使った。

**大きさや直前の拡大は記録できるが、単独で縮小を選ぶ根拠には足りない。** 選択モデルでは、1コマで縮小する表現と、縮小を選ぶ条件を分けて扱う。今後比較する入力候補は、同じ行の表示中か、次の語や行が間近に予定されているか、何を主役として見せたい区間か。表示計画から事前に得られる条件を使い、元映像の結果を見てから付けたラベルと区別する。

```powershell
python scripts/measure-phrase-choice-context.py data/Style_Attribution/report.json data/Style_Phrase_Opportunities/opportunities.json data/Style_Phrase_Choice
python scripts/evaluate-phrase-choice-context.py data/Style_Phrase_Choice/measurements.json
```
