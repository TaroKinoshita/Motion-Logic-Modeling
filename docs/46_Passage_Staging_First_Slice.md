# 参考パッセージによる生成の初版

2026-11-20。[計画45](45_Generation_Redesign_Plan.md) の P1（パッセージ辞書）・P2（移し替え）・P4（並べ方）の最小版を実装し、Test_audio1 の全6行で生成した。

## 実装

| ファイル | 内容 |
| --- | --- |
| `apps/server/src/passage-library.ts` | 参考の復元シーンから切り出した13パッセージ（Lyricsample1・4・6・7）。ブロックの役割（本文／図形）と読む順をClaudeが選定 |
| `apps/server/src/passage-staging.ts` | 読み込み・寸法計測、時間の写像、移し替え、句の分割と選択、画面外の補正 |

| `scripts/verify-passage-staging.mjs` | 恒等の検査、全編生成、ブロック版と最終版、3画面比較 |

### 処理

1. **選択**：行の語を連続する塊に分け、塊ごとにパッセージを選ぶ（動的計画法）。点数は、本文スロット数と語数の一致、時間の伸縮率、強調語と最大スロットの一致、語幅とスロット幅の比、表示される文字の高さ（中央値）、同じパッセージの連続・多用への減点。重みは設計値。
2. **時間**：パッセージの開始・終了と各本文スロットの出現時刻を、新しい区間の開始・終了と各語の開始時刻へ対応させる区分線形の写像でキーを移す。語は歌われる前には出さない。
3. **ブロック**：参考のグループ（位置・拡縮・回転・せん断のキー）をそのまま移す。本文スロットには新しい語の外形のブロックを置き、図形スロット（帯・輪・矢印）は元の輪郭を残す。
4. **外観**：新しい語を、元の字の高さに合わせ、幅はスロット幅の1.25倍以内に収めて載せる。図形は本文の後ろに淡い色で置く。反転区間は元のパッセージから引き継ぐ。

## 確認したこと

- **恒等の検査**：13パッセージすべてで、元の時刻に当てると元の変形キーと一致（誤差 < 1e-6、計1,300キー余り）。
- **全編生成**：元歌詞・別歌詞とも 336 コマ、同じ入力から同じシーン（保存後も一致）。
- `npm test`（32件）、型検査、Webビルド、規則生成の範囲検査（24生成・8拒否）が通る。

### 目視

参考の動きがそのまま出ている場面：語全体の1コマ縮小（「舞いな」「空洞で」）、輪と重なる句（「鼓動」「サンスクリット」）、帯の上の句（「咲かせ」「双眸を」）、反転した大きな二字（「空 踵」）、三字の合字パッセージ（「エーカム／そうさ／先頭に」）。

残っている問題：

- 帯のパッセージ（Lyricsample4 冒頭）は元の句が横に引き伸ばされているため、新しい語も横長につぶれて読みにくい。
- 合字パッセージに3語を当てると、前半の2語が小さい（元の字の大きさを引き継ぐため）。
- 同じパッセージ（L6の語全体の縮小、L4の帯）を多用する。辞書が13件と小さい。
- 漢字の部品の合体は、移し替えで「合わさる時刻」は再現するが、新しい語は部品の関係を持たないので意味上の合字にはならない。

## 判断したこと

- **Lyricsample5 の画面いっぱいの一字（63〜126F）は辞書から外した。** 復元ブロックがコマごとにつぶれるため、新しい語が極小または引き伸ばしになった。
- 参考の図形は `zIndex` で背景の下に回っていたため、背景を最下層に置き直した。子要素の変形キー（矢印の不透明度など）も時間写像の対象にした。

## 次の作業

2. **読みやすさの補正**：元の横つぶれが強いスロットでは、つぶれを弱めるか候補から外す。
3. **時刻合わせ（P3）**：今の語の時刻は仮合わせ。
4. **評価（P5）**：作品を1本外した再現と、条件を伏せた人の比較。

## 追記：残った問題への対応（同日）

| 問題 | 調べたこと | 対応 |
| --- | --- | --- |
| 帯の文字が横につぶれる | 元の句のブロックは、親の拡縮で幅÷高さの中央値が大きくなっていた | 本文の子だけに逆向きの横倍率をかけ、画面上の縦横比を0.9〜1.1に収める（中央値で補正）。親の動きは変えない。一瞬だけつぶれるのは元の演出として残した |
| 語が小さくなる | 合字・並びのスロットは元の字が小さく、幅の制限でさらに縮んでいた | 画面上の高さの中央値が6%を下回らないよう、元の字の高さの1.6倍までは拡大を許す。選択でも高さ8%未満・4%未満を減点 |
| 辞書が小さい | Lyricsample2・3・1中盤を確認。3の速いショット（1〜90F）は枠と字が一つの輪郭になっていて元の字が残るため使えない | 「青→青空」（小さな一字の後に大きな二字が跳んで止まる）、1中盤の左右に離れた二字、3の再構成済みの枠と縦書きの場面を追加し、16件にした |

再生成後の大変化は元歌詞 8.0回/秒、別歌詞 7.1回/秒（参考 5.9〜8.5）。テスト32件、型検査、ビルドが通る。占有範囲（0.05〜0.07）と文字の高さ中央値（0.17）は参考よりまだ小さい。
