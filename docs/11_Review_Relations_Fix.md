# レビュー対応：関係・複数区間・連動停止

ユーザーの「簡単に修正」に合わせ、既存スキーマv2の範囲で実装。文書10の「拍を秒へ解決」「1要素1区間」「単一holdのみ」の制限を以下で更新する。

## 1. 拍関係を保持

adaptでは秒キーを区間倍率で変換し、拍キーを新曲の拍番号へ対応させる。区間先頭に最も近い新曲の拍を起点とし、元の拍数を保持する。分数拍は隣接マーカーを補間、マーカー外は端の間隔で外挿する。

既存の `{beat, offsetSeconds}` を利用し、新曲の拍の揺れを基準BPMとの差として保存する。元のoffsetSecondsは区間倍率で変換して加える。出力tempoを保持するのでBPM編集にも反応する。拍マーカーやtempoがない入力はエラーにし、関係を黙って秒化しない。tempo未指定なら新曲の拍間隔中央値からBPMを求める。

比較基準の3版は従来の秒変換を明示して使い、関係による版との違いを保つ。反復every・staggerのbeatsも保持する。ただし、反復周期そのものを不規則な各拍へ可変にする処理はまだない。BPM編集で動くのはbeat部分で、offsetSecondsに保存した揺れは固定。音声の速度は変えない。

検証：新曲の拍0,0.4,1.3,1.8秒に対し、元のbeat2＋20msを1.32秒へ対応。速度変更だけの基準は1.02秒。生成BPMを120→60へ変更すると2.32秒になることをテスト。

## 2. 区間をまたぐ要素

同じelementIdを連続区間へ複数回割り当て可能にした。生成物は1要素のまま、キー時刻ごとに所属区間を選んで変換する。明示したinPoint/outPointを区間端で切らない。親子の区間一致制約も解除した。

元区間・先区間の両方が連続していることは検査する。飛び飛びの割当、重なり、同一区間内でのID重複は拒否する。区間境界をまたぐ非線形補間の厳密な時間変換は行わず、キーの補間指定を保持するため、境界付近の速度感は実素材で確認する必要がある。

検証：背景・親グループ・タイトルを前後2区間へ割り当て、後半でもタイトルが評価結果に含まれる。生成数は3要素のまま。拍の両端合わせ基準も、明示した表示範囲が拍区間外というだけでは失敗しなくなる（出力時間外の内容は画面に現れない）。

## 3. 複数トラックの停止規則

`hold_group`を追加。targetsに `{elementId, property, keyIndex}` を列挙する。各対象の連続同値キーの停止開始・終了が揃っていることを検査し、同じsecondsで停止長と後続キーを一括変更する。一つでも対象が不正なら生成しない。

親のscaleX/scaleYと子のx/yなどを対象にできる。対象外のトラックは変更しない。停止中の縮小アニメーションや音声のキック除去まで自動連動する規則ではない。必要な前後の動きは既存キーに記述する。拍キーはbeatを保持し、ずらした秒数をoffsetSecondsへ加える。

検証：親のscaleXと子のxの停止を1秒から0.5秒へ一括変更し、両方の後続キーが同じ0.5秒早まる。停止範囲が異なる対象は拒否。HTTPの規則保存と比較版生成でも2対象の変更を確認。
