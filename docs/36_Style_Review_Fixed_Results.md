# 作家判定の入れ替え検定と素材条件の再検証

2026-11-20。[レビュー後に固定した手順](35_Style_Review_Fixed_Protocol.md)を、既存の13抜粋に適用した。すでに使った素材での追加点検であり、独立した確認試験は未実施。

## 既存結果の再計算

| 比較 | 観測値 | 入れ替えで同じかそれ以上 |
| --- | ---: | ---: |
| 中央5秒、構図＋運動曲線 | 均衡正答率77.4%、10/13 | 69/1,716（p=0.040） |
| 同じ設定で運動曲線を加えた差 | 均衡正答率で8.3ポイント増 | 472/1,716（p=0.275） |
| 探索した72設定の最高値 | 均衡正答率92.9%、12/13 | 133/1,716（p=0.078） |

参考7・対照6の割り当てを全列挙し、各回で判定をやり直した。最高値の点検では、毎回同じ72設定から最高値を取った。固定設定の値は単独で見た参考値で、比較条件の探索と素材選択の偏りを含めた作家性の証拠には使わない。**運動指標を加えたことによる安定した改善は確認できなかった。** 抜粋の長さだけでも映像と同じ件数が当たった。素材の選び方を測っている可能性を排除できていない。各値は、同じ元作品を含まないことやラベル交換可能性が確かめられていない抜粋での記述値。

## 帯と背景を調整した再試験

全抜粋に5秒窓を3つ置き、抜粋ごとに集約した。前処理でLyricOther3と6の上下に安定した帯が検出された。帯を除いたうえで、周辺の色が十分そろう標本だけを使った。指定量の標本が残った11本では **6/11、均衡正答率55.0%（p=0.368）**。Lyricsample7とLyricOther3は背景判定を通る標本が足りず、分類から外れた。

背景判定は簡易な近似で、周辺に低コントラストの模様がある場合は通る。目視ではLyricOther2の網点やグリッドが一部通過した。LyricOther2・5を両方外した追加の感度確認は **6/9、均衡正答率66.7%（p=0.226）**。背景判定によって残った場面の構成も変化するため、55.0%を以前の77.4%と直接引き算して、偏りの大きさを推定しない。元動画がどこから切り出されたか、配色や題材の違いは未解決。 [背景判定を元コマで確認](../data/Style_Review_Fixed/background-audit.jpg)

## 仮説別の結果

前景成分が2個以上あり、上位2成分の外接高さが2倍以上違うコマの割合を、重複を除いて抜粋ごとに出した。レビュー後に集計を訂正し、作家判定の再試験と同じ母集団を使った。参考6本の平均は **41.1%**、対照5本は **23.6%**（差17.5ポイント、記述的 p=0.156）。枠が多いLyricsample3も外す感度確認では **31.8%対23.6%**（差8.1ポイント、p=0.230）。旧値43.6%には、背景条件で除外したLyricsample7が入っていた。枠の混入は元コマでも確認したため、新規素材では[文字だけを測る手順](38_Text_Hierarchy_Correction.md)に切り替えた。

既知の1コマ縮小は参考群で選んだ4件。縮小できる場面を両群から同じ基準で拾った分母がないため、群の出現率はまだ検定できない。未見の素材では、文字列の同一性と全体の可視性を先に採点し、縮小以外の維持や拡大を含めて数える。演出選択の最良値17/34と固定基準15/34の差についても、次の実曲の自動生成を任せる根拠は得られていない。4画面の生成試作は動きの選択と補間の比較に使用し、作風の再現度は独立評価に持ち越す。
