# M2c：領域拡大と座標目盛り

2026-11-17。追跡・曲線近似より先に、AIが位置を読むための画像取得を追加。

- MCP get_framesにregion:{x,y,w,h}、grid_stepを追加。新しいツールは増やさない。
- 座標は元動画の整数px。動画がないときはシーンpx。範囲外・非正の寸法は400で拒否。
- compareでは同じ領域を左右へ適用。シーンと元動画の寸法が異なるときは正規化座標で対応づける。
- 元画像を縮小してから切り出すと細部が失われるため、領域指定時は元解像度のフレームから切り出す。元動画を変更せず、既存フレームキャッシュを利用する。
- 目盛りは元動画座標を表示。観察画像への補助表示のみで、scene.jsonや書き出し映像に焼き込まない。
- 縮小画面の目測より計測しやすくする機能であり、これ自体が追跡やピクセル精度の自動計測ではない。

検証：`node scripts/verify-region.mjs`で切り出し寸法、矩形の期待位置の画素、範囲拒否、目盛りの有無を確認。
`node scripts/verify-beats-http.mjs`でMCPの比較画像返却、HTTPの範囲外400を確認。
生成画像は `data/v2-validation/region-compare.jpg`。0.5秒、領域(350,230,580,300)、目盛り50px。画像を目視確認した。
既存core20テスト、型チェック、UIビルドも成功。

制約：切り出しUIはまだない（MCP/HTTPのみ）。元解像度のデコードを使うため極端な高解像度素材ではメモリ負荷が増える。座標目盛りと時刻ラベルが画像に重なるため、画像評価・追跡の入力にはgrid_stepなしを使う。
