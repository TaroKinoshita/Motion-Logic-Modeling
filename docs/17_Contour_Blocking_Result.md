# Lyricsample1 全編の輪郭・動き・関係

前回の版は冒頭だけ実測し、矩形に新しい書体を合わせた。字形の傾き、短い重なり、非線形な潰れが削られていたので、場面ごとに元フレームから輪郭を取る方式に変更した。全183フレーム、7.625秒を対象にした。作品のタイミングを目視確認した区切りを9箇所指定し、すべての画面座標を同じ手順で計測した。

- 06・07は、合字の時刻を1フレーム早めた版と遅らせた版の中盤23フレーム。工程比較プロジェクトの仮説・規則と観察から生成した。
- MLMのプロジェクトは `p_mwljb45yi4uq`。箱の位置・寸法はキー、見た目は同じブロックの子のポリゴンとして保持する。輪郭は穴を保存し、白黒反転ごとの背景輝度と前景を描き直す。最終調整は元素材から抽出した輪郭による映像で、文字への置換は編集画面で行える。

輪郭追跡は191軌道・計1100観測。ワーカーの実行は最終測定で約2.1秒（モデル読み込みを除く。フレーム読込、輪郭化、指定フレームのOCRを含む）。小さなルビ・粒子・一時的な輪郭も軌道として残す。作業時間には範囲指定、部品の確認、意味付けが含まれるため、人の短縮率は未計測。

## 実装・検証した工程

- 中間①で箱を1コマだけ直し、範囲を指定して再計測できる。軌道の分割、複数ブロックのまとめ・解除、輪郭から文字への置換を保存する。共通移動の候補は支持数と残差を保存し、97〜103Fを親グループへ分ける前後で画面座標が一致することを検証した。共通運動は候補として提示する。
- 中間②で出来事の確定・却下、拍への関連付け、拍との時間差の採取、手動の拍・小節頭・区間マーカーの保存を行う。確定イベントに観察を結び付け、合字の時刻を±1Fずらしてブロック・輪郭・時刻が揃う比較版を生成した。
- M4はシーン、ブロックの寸法、表示・遮蔽区間、出来事と外観を一緒に変換する。観察は元映像の時刻と出典を保持する。合成音源と不規則な手動拍で192フレームの比較MP4を検証した。全体速度、拍の両端、各拍の局所対応、固定テンプレートの比較基準を生成した。
- 分析と4面書き出しは進捗、中断、再試行を追跡する。リビジョン衝突を拒否し、履歴からシーン・資料・参照メディアを復元する。新しい大きな履歴はgzipで保存し、従来のJSON履歴も読める。旧音声は履歴参照用に保持する。

## モデルと残る検証

- OpenCVで全編の輪郭を計測。PP-OCRv5 Mobile ONNXのCPU推論で特定コマの読み候補を保存した。字幕の細かい粒度や接触時の読みは確認が必要。モデルと依存の版は固定した。
- SAM 3.1のキャッシュに重み3.50GBを確認した。ユーザーは端末上の `vrecon` のコードと環境の実在を確認済み。こちらの実行セッションから同じパスを読み取れず、専用Pythonでの推論は未確認。システム側で確認したPyTorch 2.5.1+cu121は別環境。SAMの速度・精度・VRAMは未実測。 [端末上の場所と導入判断](18_Vectorization_Tools.md)・[Metaの公式要件](https://github.com/facebookresearch/sam3#installation)
- 小節頭・楽曲区間は手動編集に対応し、同じlibrosa環境で4拍子仮定の小節頭と音の変化点の候補を作れる。Lyricsample1では小節頭候補4件、20拍未満のため変化点は出力対象外。人が聴き取った正解との照合と、All-In-One系による楽曲区間ラベル推定は未検証。背景が複雑な素材での分解器比較、別の実曲での受け入れ試験、M5は残る。
