# v2実装・検証記録

実施日：2026-11-17（日本時間）。設計承認：「どんどん実装を進めて…なぜそうしたか、ちゃんと根拠を残しておいて」。

## 実装した範囲

- M2a：スキーマv2、v1移行、拍時刻・秒オフセット、周期反復、文字／単語分割、時間差、unitTransform、アンカー、登録フォント。
- UI：BPM、文字分割、秒の時間差の編集、関係から展開したキーの読み取り専用表示、文字単位の軌道、分割文字全体の選択・ドラッグ。
- 保存：読み込み時はメモリだけでv1を移行。変更時にv2で保存。v1の履歴も新リビジョンとして復元できる。
- M2dを前倒し：右パネルで推定マーカーの確定／却下／一括削除。既存setMarkersを使い、MCPツールは12個のまま。
- M2bの拍推定、M2cの領域追跡・計測APIは未実装。今回のSSIM自動化は受け入れ試験スクリプト内のもの。

## 判断と根拠

| 判断 | 根拠 |
|---|---|
| transformとunitTransformを分離 | 合成素材のMOTIONは登場をずらした後、全体が同時に上昇する。既存キー全体をずらす設計ではこの2つを分けられない |
| 拍時刻と拍の長さを別型にする | tempo.offsetは絶対時刻だけに必要。時間差や周期に加えると誤った遅延になる |
| 秒キーを維持し、拍キーの順序逆転を拒否 | 計測したずれを丸めない方針。混在キーをBPM変更で勝手に並べ替えると、観察値の意味が変わる |
| 反復を評価時刻の変換で処理 | 周期が短いほど保存・描画のキー展開が膨らむ。タイムラインだけ表示範囲内に展開し、最大2000件で表示省略を明示 |
| 初期フォントをMLM Arial 400/700に限定 | Windowsの既存arial.ttf/arialbd.ttfを明示登録し、同じファイルをローカルHTTPでブラウザへ渡せる。未登録名のフォールバックを防ぐ。フォントファイルはリポジトリにコピーしない |
| v1専用スキーマを固定 | 新形式をv1として誤受理せず、履歴を元の形式で保持するため |
| 選択枠は単語全体、描画・当たり判定は単位ごと | 最初の1文字の中心を使って全体を回転・拡縮する誤りを防ぐ。アンカー位置と幾何学的中心も分離 |
| 軌道をシーン単位でキャッシュ | 分割文字の全フレーム評価を再生の毎フレームで繰り返す必要がない |
| マーカー修正を先に実装 | 追加依存が不要で、合成試験で既に判明した4.567秒・4.6秒の誤検出を即修正できる |

判断は手元のコード、生成サンプル、実行結果に基づく。新規外部ライブラリ・モデルのダウンロードは行っていない。

## 実行して確認したこと

- `npm test`：20件成功（既存11＋新規9）。拍変換、反復境界、v1移行、文字遅延と全体動作、書記素、親付きアンカー、反復情報を保持する編集など。
- `npm run typecheck`：全4パッケージ成功。
- `npm run build`：成功。
- `node scripts/verify-v2.mjs`：隔離した`data/v2-validation/`でAPI、SDK経由のMCP、FFmpegを実行。ローカル接続はサンドボックスのEACCESが出たため、許可を得てサンドボックス外で実行した。
- v1を読むだけでは元のscene.jsonを書き換えない。変更後のschemaVersionは2。v1履歴への巻き戻し成功、元履歴は1のまま。
- MCP：12ツール、BPM変更、画像コンテンツ返却、古いリビジョン拒否。
- v1/v2の10秒MP4は両方ともffprobeで300フレーム。
- ブラウザ：BPM120→100、時間差0.06→0.1秒、分割テキスト全体のドラッグを確認。各操作で1リビジョン増加。文字描画、選択枠、単位の軌道、展開キーを目視確認。
- ブラウザ：推定カット4件から4.56667秒・4.6秒を各1操作で却下。4.5秒を確定し、残りの推定を一括削除。確定済みと元の手動マーカーは保持された。

## 制約と残り

- 一定BPMのみ。可変テンポ・小節表記・歌詞の発声解析は未対応。
- 文字分割は横書き一行。wordは空白区切り。高度な組版、任意フォントの登録UI、文字ごとの個別ドラッグは未対応。
- フォントを省略した既存シーンは従来のフォールバック。ブラウザとSkiaのピクセル完全一致は未証明。同じファイルを使うことと描画結果の完全一致は別。
- UIの秒キー操作は従来どおり。分割・拍・反復を持つ行のキーはJSONから編集。展開キーは単位ごとの別行ではなく元要素の行へまとめて表示する。
- 反復の終了時点は左側極限を保持する。有限精度のため境界の直前へ数ULPずらして評価する。
- BPM変更でscene.duration・音声は変わらない。範囲外に出たキーは描画範囲で切られる。範囲外イベント一覧の専用UIは未実装。
- 却下はマーカー削除。却下理由や再検出を抑制する履歴は未実装で、再解析すると同じ候補が再び現れ得る。確定後も再解析で同時刻の推定が追加され得る。既存manualマーカーは保持する。
- マーカー修正は右パネルから。タイムライン上の直接操作は未実装。拍マーカーも同じUIで処理するが、拍推定器との結合検証はまだ。
- 新規フォント・大規模テキスト、回転／拡縮ハンドルのv2ブラウザ全ケース、長尺、実素材、新曲での構成、AE出力は未検証。
