# 出し切った構図から動きを逆算する

2026-11-20。ユーザーの提案「文字を出し切った時の構図を先に考え、そこから逆算して動きを作る」を実装した。あわせて [文書47](47_Motion_Feedback_And_Structure.md) の残った問題を直した。

## 調べたこと

構図の美しさを数値で扱う研究は、デザインの原則を指標にして候補を採点・最適化している。

- 自動文書レイアウトの美的指標：整列、規則性、分離、バランス（視覚的な重さの重心）、余白の割合（Harrington ら、[ResearchGate](https://www.researchgate.net/publication/221353078_Aesthetic_measures_for_automated_document_layout)）
- 文字と画像のレイアウト生成を、バランス・統一・密度・比率の規則によるエネルギー最小化として解く（[Microsoft Research](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/08/a33-yang.pdf)）
- タイポグラフィのポスター自動生成の評価指標：整列、バランス、余白など10項目。文字の箱の視覚的な重さを「面積×濃さ」とする（[arXiv 2402.06945](https://arxiv.org/pdf/2402.06945)）
- 視覚的なバランスを物理のモーメントの釣り合いとして計算するモデル（[Symmetry 2025](https://doi.org/10.3390/sym18010041)）

「最終フレームを先に決め、逆算して動かす」手順そのものを書いた文献は見つからなかった。動きは意味を導入してから安定した状態に落ち着くべきだ、という指針はある（[SVGator](https://www.svgator.com/blog/kinetic-typography-a-guide-to-text-in-motion/)）。今回の実装はこの「落ち着く先」を先に設計する形になっている。

## 実装

### 1. 構図（ロックアップ）の設計　`apps/server/src/lockup.ts`

行の最終的な語の並びから候補を作り、採点して選ぶ。

- **候補**：配置6種（左揃えの段組、中央揃え、右揃え、主役を最上段、一列、段ごとにずらして傾ける）×主役の高さ3段階×大小比2段階＝36案。主役は強調語。なければ漢字の多い語。主役は単独の段に置き、ほかの語は読む順に詰める。安全域（幅84%・高さ76%）に収まるよう全体を縮める。
- **採点**：面積で重み付けした重心と視覚上の中心（画面中央よりやや上）との距離、占有範囲（10〜26%を目標）、主役の大きさ、最小文字の大きさ（画面の5.5%未満を減点）、縮小の度合い、前の行と同じ配置の減点。最高点から0.4以内の案から乱数で選ぶ。重みは設計値。

### 2. 動きの逆算　`apps/server/src/passage-staging.ts`

参考パッセージの動きの形はそのまま使い、語が落ち着く時刻にちょうど構図の位置・大きさ・角度になるよう、軌道全体を平行移動・拡縮・回転させる。その後は行の終わりまで静止する（画面の動きはカメラが担う）。語は消えずに積み上がり、行の終わりに構図が完成する。部品の合字では、部品は元の寿命で消え、完成した字だけが構図に残る。

拡縮をそろえると入りの瞬間が画面を大きくはみ出すことがあるため、入りの拡大を画面幅の1.05倍までに抑える。

### 3. 残っていた問題の修正

| 問題 | 対応 |
| --- | --- |
| 動きがせわしない | カメラの動きを、音の大きい行（順位0.6以上）だけ場面ごと、ほかは行ごとに1回にした。語が消えずに残るので、画面の入れ替わりも減る |
| 語が重なって読みにくい | 静止状態は構図で重ならない。入りの途中の一時的な重なりは残る |
| 「サンスク／リット」のような分割 | 語は文字の種類（漢字・ひらがな・カタカナ）が変わる位置でのみ分ける。変わる位置がなければ分けない |
| 反転の多用 | 反転は音の大きさの順位が0.8以上の行だけ。行の中では背景の明暗を変えない（残った語が背景と同じ色にならないように） |

## 結果（Test_audio1）

| 指標 | 参考7本 | 文書47 | 今回 元歌詞 | 今回 別歌詞 |
| --- | --- | ---: | ---: | ---: |
| 大変化（回/秒） | 5.93〜8.53 | 10.3 / 10.5 | 5.8 | 5.1 |
| 占有範囲 | 0.08〜0.25 | 0.15 / 0.09 | 0.18 | 0.25 |
| 最大ブロック高 中央値 | 0.13〜0.36 | 0.28 / 0.23 | 0.27 | 0.32 |

選ばれた構図（元歌詞）：主役を最上段（「皆」）、傾けた段組（「サンスクリット／求道系」「さあ／剽悍な／双眸を」）、中央揃え（「抉り抜いた／鼓動／咲かせ」）、右揃え、主役を最上段（「空」）。重心のずれは対角線の0.8〜1.7%。

確認：テスト32件、型検査、ビルド、規則生成の範囲検査、恒等の検査、同じ入力から同じシーン。

## 残っていること

- 入りの途中で、後から入る語が先に置かれた語に一時的に重なる。
- 語数が多い行（6語）は、脇の語が小さくなる。
- 構図の候補は6種の配置の組み合わせだけ。参考作品の構図（大小の極端な対比、図形と一体になった配置）から構図そのものを学ぶ段階には入っていない。
- 構図の良し悪しは指標による採点で、人の評価は未実施。
