# 作家判定と演出選択モデルの検証計画

[理論モデリング計画](23_Theoretical_Modeling_Plan.md) の形式化と [言葉の理論](24_Verbal_Theory.md) のT1〜T7を、測定・作家判定・生成で検証する。初回は既知の同担当群と、条件をそろえた別担当群の比較。判定対象は映像担当者のクレジットが確認できる範囲とする。

## 研究から採る方法

- FörgerとTakalaの研究は、演技例と比較注釈から、知覚される動きの作風に寄与する特徴を選んだ。MLMでは、測定候補をあらかじめ挙げ、人が差を感じるかを同条件の比較で確かめる。Aristidouらの114指標はダンスのスタイルを定量化し、合成でスタイルの一貫性を保つために用いられた。 [Animating with style](https://research.aalto.fi/en/publications/animating-with-style-defining-expressive-semantics-of-motion/) · [Style-based motion analysis](https://www.andreasaristidou.com/publications/papers/Style-based_motion_analysis.pdf)
- 絵画の作者帰属を扱う制御実験では、題材や材料などの条件から手の違いを切り出して調べている。MLMでは近い題材の対照を用意し、映像の外観を含めた判定と、外観をそろえたブロック版での判定を比較する。 [Discerning the painter’s hand](https://www.nature.com/articles/s40494-021-00618-w)
- Brownieの分類に従い、画面の配置変化、要素の位置・回転・アフィン変形、変形を除いても残る字形の変化を観測で区別する。Schusterらの三角形課題ではジャークが描かれた行動の読み取りと関係した。加減速の質はMLMで検証する候補に含める。 [Brownieの博士論文](https://uhra.herts.ac.uk/id/eprint/16446/) · [Schusterら](https://www.nature.com/articles/s41598-021-97660-2)
- Cumminsの区別を使い、観測された規則性を手がかりに、入力から演出の選択を予測できる計算論的モデルを作る。制約の重みはそのモデルのパラメータであり、作者本人の思考手順は制作過程の資料を集めた場合に別途検証できる。 [Cummins](https://home.csulb.edu/~cwallis/382/readings/690/Cummins/cummins.how.vs.laws.00.pdf) · [Coherence as Constraint Satisfaction](https://cogsci.uwaterloo.ca/~pthagard/Articles/Pages/Cohere.Constrain.html)

## 実行順序と完了条件

| 段階 | 作業 | 完了条件 |
| --- | --- | --- |
| 1. 測定の定義 | T1〜T7とA1〜A6を、構図・運動曲線・字形・時間に対応付ける。各指標の入力、比較単位、単位系、欠測理由を決める。主役は字・語・意味上の中心の候補を残す。 | 測定表と、原画で確認した小規模な採点用コマがある。 |
| 2. 7抜粋で測定 | 既存の中間①・②と修正版を利用し、元のコマから連続軌道を確かめる。大きさ・占有率・余白、速度・加速度・ジャーク・停止・行き過ぎ、局所字形、切り替え・発音や拍との時差を測る。人の「らしさ」の注釈があれば時刻と理由を保存する。 | 各抜粋で値と測定可能な割合が出る。手動採点と照合し、推定方法を変えても傾向が保たれる項目を確認する。 |
| 3. 作家判定 | 近いジャンルの3〜5本を同じ手順で扱う。可能なら複数の別担当を含め、言語・歌詞主体・画面構成・曲調が近い素材を揃える。全版で同じ特徴定義を使い、特徴群を減らした場合も比較する。 | 作品別に同担当／対照／保留の判断と、特徴ごとの寄与を示す。少標本の探索結果として、対照構成を変えたときの変動も記録する。 |
| 4. 選択モデル | 「食＋反→飯」と別種の区間を使い、候補を列挙する。Aの重み付き制約、Bの部分集合選択、Cの近い事例の再利用、作家共通の基準を同じ入力で比較する。 | 少数のパラメータで未見作品の演出候補をどこまで上位に置けるかを出す。等価な重みや反例も記録する。 |
| 5. 生成と知覚評価 | 同じ新規歌詞・音源・フォント・描画条件で、推定モデル、対照／共通基準、特徴を一つ外した版を生成する。条件を伏せ、順序をランダム化して比較する。 | 「参照の作風に近い」と「読みやすい」を別設問にし、判定者間の一致と「判断できない」も記録する。 |

段階1・2と段階4の手計算・反例試験は現在の素材で進められる。段階3では対照素材が必要。新しい曲での知覚評価には素材と判定が必要。合字以外のカタカナ行や拍不明の区間も選択モデルの反例に含める。

## 比較の設計

- **作品を比較単位にする。** 7抜粋の元作品・曲・担当範囲を確認する。同じ作品からの抜粋は同じ側にまとめる。曲・シリーズの共有も記録し、同じ固有素材が学習側と評価側に漏れた場合は別集計にする。学習側で特徴選択・閾値調整を行うか、初回から定義を固定する。各保留作品の予測と欠測を報告する。 [Varma & Simon](https://pmc.ncbi.nlm.nih.gov/articles/PMC1397873/) · [Varoquaux](https://arxiv.org/abs/1706.07581)
- **混ざりやすい手掛かりを検査する。** 多数派予測、条件をそろえた少数特徴の判定を比較基準に置く。色・書体・エフェクトを含む外観、外観をそろえた配置と動き、音を外した版を別条件として評価する。Lyricsample7のエフェクトは動き評価の対象外にする。作品や歌詞の記憶で答えた場合も記録する。
- **動きの計測範囲を先に決める。** 時間は秒、並進は画面対角に対する比も保存する。元動画のフレームから測れた連続軌道と、モデルの補間曲線から計算した値を別に保持する。カット、IDの断絶、1コマの意図的な跳躍はイベントとして扱う。連続運動だけで平滑化前後・異なる窓幅を比較し、短すぎる区間のジャークは欠測にする。停止の長さや速度ピークの位置も併記する。
- **演出の機会を数える。** 合字の分母は、対象の文字部品や表記が使える区間。未採用、入力から候補にならない、観測不能を区別する。T1の同時表示時の大小比と、別時刻での規模の変化も別々に計測する。拍と発音時刻は出典と不確かさを保存し、観測が足りない区間は集計から分ける。
- **重みが決まる範囲を確認する。** 必須の歌詞表示や候補が競合するときの条件を明示し、すべて棄却しても得点できる例を検査する。複数の重みが同じ演出を選ぶときは範囲として報告し、差を判定するにはどの区間が要るかを書く。評価は実際の選択の順位と、採用・見送りの根拠から行う。

着手順は、測定表を確定し、Lyricsample1の合字、2の急減速、6の1コマ縮小を同じ表に記入する。この3例で連続運動・不連続イベント・意味に依存する選択を扱えることを確かめてから、7抜粋全体に広げる。 [レビュー修正版の範囲](23_Corpus_Review_Corrections.md)
