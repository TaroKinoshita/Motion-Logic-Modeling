# 作家性レビューを受けた固定手順

この文書の前景成分を使う指標は既存素材の点検用。新規素材の主指標は、[文字ブロックを確認する改訂手順](38_Text_Hierarchy_Correction.md)を使う。

2026-11-20。既存素材への再試験の手順を実行前に固定する。素材と初回結果は既知なので、以下は探索結果の点検。次に集める素材では、この手順を結果を見る前に固定して別の試験として扱う。

1. 既存の13抜粋の中央5秒・行背景差分・構図＋運動曲線を維持し、参考7／対照6の全1,716並べ替えで均衡正答率と構図単独からの差を点検する。探索した設定は、全13本と7番除外を同じラベル割り当てから計算する。各割り当ての最高値を全設定の観測最高値と比較する。切り出し長だけの判定も交絡の点検として出す。
2. 交絡を減らす再試験では全素材から5秒を3区間取る。区間の開始は、抜粋のうち5秒を置ける範囲の25%、50%、75%の点。画面上端・下端で、安定して検出できる帯を除く。静かな色のタイルが画面周辺の3分の2以上で共通するフレームを残す。無地背景の近似判定として使い、条件を満たした数を素材ごとに出す。構図＋運動曲線の測定設定は前項に固定し、各窓の特徴値を抜粋内で平均してから判定する。5秒を置ける範囲が異なるので、全抜粋の相対位置を近づける手順である。元作品の同じ編集上の位置を照合するには作品全編が要る。
3. 仮説の主指標は、前景成分が2個以上あるフレームのうち、上位2成分の外接高さが2倍以上違う割合。フレームを独立標本にせず、重複標本を統合して抜粋ごとに割合を出し、群平均の差を比べる。図形や字の断片を含むため、意味上の主役の判断は別に残す。1コマでの切り替えは、元fps・同一語・全体可視の確認ができた例を使い、分母を整えられない場合は出現率として扱わない。

再判定に使う抜粋は背景条件を通った異なる標本が30コマ以上あり、少なくとも1窓で速度変化が3点以上あるもの。大小差には、比較できる異なる標本が12コマ以上ある抜粋を使う。どちらか一群が2本未満のときは、その集計を保留する。

曲・シリーズ・編集担当の独立性および素材の抽出条件は既存ファイルからは確認できていない。ラベル並べ替えは「この13抜粋で群ラベルを交換できると仮定した場合」の参考値。新規素材の試験では、近い音楽・言語・背景の各群10〜15本を収集目標とし、元作品と担当、抽出位置、背景条件を評価前に記録する。本数は十分性の保証とはせず、実際の効果幅とばらつきを見て試験規模を決める。
