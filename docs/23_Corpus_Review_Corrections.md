# 文字の取り違えと差し替えの再検証

修正版6本の4画面、差し替え動画、元動画・旧版・修正版を並べたコマ比較は [修正版の一覧](../data/Lyricsample_Corpus_Editable/Corrections/INDEX.md)。旧版との照合には元の出力フォルダーを使う。

| 素材 | 照合したコマ | 修正と根拠 |
| --- | --- | --- |
| 2 | 30、42F | 42Fの「得」の欠落を確認。長くつながった複数の軌道から字を合成する代わりに、同じ語が続く範囲から字列を固定輪郭化した。 |
| 3 | 15、18、72、75F | 18Fで重なった「む手」と余分な線を確認。72Fの右字と75Fの右字は字形が異なるため、同じ代表形を共有させない。 |
| 4 | 12、20、108、116、130、151、179F | 「伝」と後続語を一組として差し替え、強調字の親変形を維持した。矢印は色で本文から分離し、「あ」「の」の元の断片を抑えた。元訳は差し替え対象区間で非表示にし、アプリと生成条件で要確認を示す。 |
| 5 | 37、39、78、82、273、275、276F | 37Fの軌道が48Fの「澄まし」を代表形にしていた。場面を分け、78Fの二重の「ね」と273F以降の別段階の形が混ざる箇所も、元の変化を見ながら分けた。 |
| 6 | 190、191F | 190Fの親は186Fの形を使っており、子への変換は描画で合成されていた。小字を含む190Fの構成を別の固定形にし、191F以降と区切った。 |
| 7 | 93、95、98F | 左右に重なった「前」を、高コントラストの一つの輪郭から再構成した。エフェクトの再現は対象外。 |

一般の代表形生成でも、指定済みのカットをまたいで同じ代表形を選ばないようにした。5を含む修正版の境界は元コマを見て与えたもので、全編の自動での文字交代検出は未検証。重なった字や枠をまとめた固定輪郭も残る。

監査JSONには元・旧版・修正版のOCR文字列と信頼度、同じ範囲での前景IoUを記録した。OCR不一致は両側の信頼度が0.9以上の場合だけ数える。縦横に変形する字、枠と接触する字の多くは要確認になるため、判定保留を一致に含めない。目視指摘8件を確認コマとして保存した。映像全体で読める誤りの件数、拍への意図的な同期、作家固有性は判定していない。
