# 語の縮小・停止・急減速を対照素材で照合

2026-11-20。[初回の作家判定](28_Style_Attribution_Control_Result.md)に続き、参考7本と対照6本の元映像4,012コマを、各素材のフレームレートのまま走査した。ここでは「同じ映像担当に近いか」の分類に数値を足す前に、同じ語が動いていることと、似た現象が別担当にも出るかを元コマで確かめた。

## 確認した例

| 素材・語 | 変化した元コマ（0始まり） | 直後の幅・高さ／直前 | 直後から2コマ後まで |
| --- | --- | --- | --- |
| Lyricsample5「ユラユラ」 | 196→197 | 幅43%、高43〜44% | 幅・高さとも2%以内 |
| Lyricsample5「カラカラ」 | 280→281 | 幅43%、高43〜44% | 幅・高さとも2%以内 |
| Lyricsample6「やめろよ」 | 128→129 | 幅41%、高40% | 幅・高さとも2%以内 |
| Lyricsample6「回った」 | 273→274 | 幅・高40% | 幅・高さとも2%以内 |
| Lyricsample5「顔が」 | 52→53 | 幅38%、高45〜46% | 幅・高さとも約6%再拡大 |
| LyricOther2「余計」 | 254→255 | 幅67%、高72% | 幅・高さともさらに約20%縮小 |
| LyricOther4「痛い」 | 283→284 | 幅77%、高78〜79% | 幅・高さとも2%以内。縮小と同じコマで白から赤に変化 |

元解像度で語全体が入る領域を指定し、40・50・60の三つの差分閾値で文字の外接矩形を再測定した。表の幅と高さはその三条件を丸めた範囲。LyricOther4は赤に切り替わるので色差、それ以外は輝度差を使った。「顔が」は縮小幅が大きくても直後に戻る。対照の「余計」は段階的に縮み、「痛い」は縮んだ後の寸法が安定する。語を一斉に縮めることや、縮小後に寸法を保つことは、別担当の映像にも出る。

今回の参考群では、**語全体が1コマで高さ約40〜44%になり、次の2コマもほぼ同じ寸法を保つ**例が2本で4件あった。今回確認した対照例では縮小量とその後の推移の組み合わせが違った。確認できた場面を記述するための候補で、こうした場面が出せた機会の総数や検出漏れは未測定。作家判定の特徴に採用する場合は、条件を固定してから別の素材で確かめる。

## 停止と急減速

- Lyricsample2の「青空」では「青」が77→78Fに右へ162.5px、その後25、10、4、1pxと移動量が減り、82→87Fは1コマ当たり1px以内だった。この急減速は単字の軌道で、「空」を含む語全体には適用しない。
- LyricOther4の310〜314Fの「痛い」は、幅・高さがいずれも2%以内の変化に収まり、中心には小さな移動が続いた。LyricOther5の233〜237Fにも近い位置を保つ文字列があり、停止に近い見せ方は両群にある。停止の直前に同じ語が速く動いたかは別の判断とした。
- 急移動後の停止の候補には、ほぼ同形の字や部品を取り違える例があった。LyricOther1の252F付近の「いい」や、LyricOther2の206F付近の文字追加を、文字列全体の急減速には数えなかった。現時点では、語全体の急減速がどちらの群に多いかは保留。

## 走査と再実行

640×360で行ごとの背景色との差から前景を取り、単独成分と近接する成分の塊を作った。隣接コマで位置・縦横の寸法・寸法を正規化した輪郭を比較し、全画面の変化が大きい境界をまたぐ候補を除外した。停止には0.12秒以上の低速区間を、急移動にはその前の約0.2秒の速度を使った。輪郭の類似度だけでは文字、点、枠、同じ字の反復を区別しきれないため、件数は候補の件数として保存した。候補は各素材・各種類の上位3件をコマ一覧に出した。Lyricsample7も処理範囲の確認には使い、エフェクト付きの場面は上記の比較表に入れていない。

```powershell
python scripts/audit-phrase-motion.py data/Style_Attribution/report.json data/Style_Phrase_Motion
python scripts/measure-phrase-checkpoints.py data/Style_Attribution/report.json data/Style_Phrase_Motion/checkpoints.json
```
