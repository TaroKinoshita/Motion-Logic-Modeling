# 動きの指摘への対応と、構成・見立て・見た目の層

2026-11-20。ユーザーの指摘（オリジナルらしさのための人の意見）と追加の依頼を、パッセージ生成（[文書46](46_Passage_Staging_First_Slice.md)）に組み込んだ。実装は `apps/server/src/passage-staging.ts`、`apps/server/src/kanji-parts.ts`、`apps/server/src/lyric-planner.ts`。

## 指摘と対応

| 指摘 | 対応 |
| --- | --- |
| ブロックは大まかな位置とサイズ。中の文字はもっと個別のパーツで動かすべき | 語を文字単位に分け（`split: 'char'`）、文字ごとに時間差で入る。入り方は6種（拡大して戻る、上から落ちる、回転、横から滑る、横幅0から開く、切り替えのみ）から乱数で選ぶ。ブロックの動きは変えず、文字の動きはブロックの中で重ねる |
| 縮んだまま次の歌詞に行くのは不自然 | 本文のブロックについて、3コマを超えて続く横つぶれと、表示の最後4コマのつぶれを等倍に戻す。1コマで65%未満に縮んだ場合は6コマかけて元の大きさへ戻す（少し行き過ぎて戻る） |
| 回転と奥行きがなく、XY移動だけで単調 | 行ごとにカメラを置く。画面中央を軸に、押し込み・引き・振り（素早い回転）・傾き・漂いを場面ごとに乱数で選ぶ。拡縮で奥行き、回転で傾きを出す。音の大きい行ほど振れ幅を大きくする |
| 単語をもっと細かく刻む | 4文字以上の語を2つに分け、後半は語の区間の45%の時刻に出す |
| 出し方が単調。バリエーションとランダム性を | 場面の選択を、最高点から0.8以内の候補の中から乱数で選ぶ。入り方とカメラも乱数。乱数は種つき（同じ入力と `variation` で同じ結果） |
| 加速して入り、行き過ぎて少し戻る動き | 入り方とカメラ移動に、行き過ぎて戻るイージング（3次ベジェ、終端1.35）を使う |
| イーズはもっときつく。リニアをやめる | 参考のキーで2コマを超えて空く線形区間を、強いイーズイン・アウト（0.9, 0, 0.1, 1）に置き換える。密に計測されたキーはそのまま |
| カメラワークが固定 | 上記のカメラ |

## 追加の依頼

| 依頼 | 実装 | 根拠と限界 |
| --- | --- | --- |
| 曲全体の構成 | 各行の音の大きさ（RMS）をFFmpegで測り、曲内の順位にする。大きい行は見せ場の場面（大きな字、反転、合字、語全体の縮小など）を、小さい行はつなぎの場面（句、帯、矢印、並び）を優先し、カメラの振れ幅も変える | 音の大きさだけの推定。サビや区間の判定ではない |
| 字の見立て | 一字の語で部品の組が分かるもの（例：空＝穴＋工、踵＝足＋重）を、部品・部品・字の3つに展開し、合字パッセージ（Lyricsample1の「食＋反→飯」）に当てる。3つは一つの場面から分けない | 部品表は手作りの約110字（`kanji-parts.ts`）。完全な分解辞書（KanjiVGなど）は未導入。見立ての意味の良し悪しは判断していない |
| 見た目の底上げ | 文字の高さの下限を画面の8%に。同じ場面の再使用を強く減点（1回ごとに2.2点）。書体は1種、配色は紙色と墨色、図形は淡い中間色に統一 | 辞書の追加は文書46の16件のまま |

## 結果（Test_audio1、元歌詞・別歌詞）

| 指標 | 参考7本 | 文書46 | 今回 元歌詞 | 今回 別歌詞 |
| --- | --- | ---: | ---: | ---: |
| 大変化（回/秒） | 5.93〜8.53 | 8.0 / 7.1 | 10.3 | 10.5 |
| 占有範囲 | 0.08〜0.25 | 0.05 / 0.07 | 0.15 | 0.09 |
| 最大ブロック高 中央値 | 0.13〜0.36 | 0.17 | 0.28 | 0.23 |
| 最大ブロック高 90% | 0.32〜0.93 | 0.41 / 0.36 | 0.72 | 0.88 |

文字の大きさと占有範囲は参考の範囲に入った。大変化は参考より多く、せわしない側に外れた。

目視：「空洞で」「求道系」「剽悍な」などで文字ごとに落ちる・回る入り方が出る。カメラの傾きと拡縮で画面が常に動く。「穴→工→空」「足→重→踵」が部品から字へ切り替わる。

残る問題：

- 動きが参考よりせわしない（大変化が参考の上限を超える）。カメラと文字の入りを両方入れたため。
- 二字の入れ替わり場面（Lyricsample7「系」「统」）で「剽悍な」と「双眸を」が重なって読みにくい。
- 「鼓動」が接する二字目（「咲かせ」）を覆う。参考の接触の演出だが、長い語では読みにくい。
- 4文字以上を機械的に二分するため、「サンスク／リット」のように語の切れ目と合わない。
- 時刻は仮合わせのまま。人による評価は未実施。

確認：恒等の検査（位置・回転のキー）、同じ入力から同じシーン、テスト32件、型検査、ビルド、規則生成の範囲検査（24生成・8拒否）。
